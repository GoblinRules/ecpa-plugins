Local workspace

Unlock your workspace

Use the proxy management key to access files on the core machine.

Remembered keys are stored in this browser profile. Other pages on the same proxy origin can access that storage.

About this tool

Custom paths: use this plugin’s Configure button in ECPA.

Select an item

Select files to capture, or select saved files to apply.

Previous versions

Restoring previews the complete previous file. A backup of the current file is made when you apply it.

Review changes

Check each destination and its proposed content. Applying writes files on the core machine and backs up existing content. A multi-file apply can stop partway if a write fails.
