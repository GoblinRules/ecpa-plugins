Z.ai Provider

Connect an existing Coding Plan key. This plugin never creates, rotates or deletes keys.

1. Connection details

Create the key in the official Z.ai dashboard and check its account, organisation and billing type there. Only Coding Plan keys are supported by this setup. The plugin cannot independently verify billing classification.

2. Review and confirm

The key will be stored in ECPA’s native credential store, not Windows Credential Manager. Users authorised to call this proxy may use its Z.ai models. Your display name is a label, not a verified account identity.
